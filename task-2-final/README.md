# Task-2 Professional PHP CRUD Blog

## Features
- User registration
- Secure password hashing
- Login/logout with PHP sessions
- Create, Read, Update, Delete blog posts
- Responsive professional UI
- Global shared CSS
- Prepared SQL statements

## Run with XAMPP
1. Put the `task-2` folder inside `C:\xampp\htdocs\`
2. Start Apache and MySQL in XAMPP.
3. Import `database.sql` in phpMyAdmin.
4. Open:
   `http://localhost/task-2/register.php`

## Important
The local `config/db.php` contains your database credentials.
Do not push real passwords to a public GitHub repository.
