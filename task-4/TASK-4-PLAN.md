# Task-4 — 10 Day Implementation Plan

## Day 1
Create the `blogs2` database and prepare the new Task-4 project structure.

## Day 2
Configure PDO and disable emulated prepared statements.

## Day 3
Convert authentication and CRUD database operations to prepared statements.

## Day 4
Create reusable server-side validation functions.

## Day 5
Add HTML and JavaScript client-side validation.

## Day 6
Add the `role` field and Admin / Editor session data.

## Day 7
Implement role-based authorization for editing and deleting posts.

## Day 8
Create the Admin User Management page and role update workflow.

## Day 9
Add CSRF tokens, session hardening, XSS escaping, and secure image uploads.

## Day 10
Test SQL injection protection, validation, roles, CRUD, search, pagination, and responsive UI.
