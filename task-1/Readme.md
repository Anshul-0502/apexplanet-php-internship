# ApexPlanet PHP Internship — Task 1

Basic development environment for PHP and MySQL.

## Tools
- XAMPP
- PHP
- MySQL
- Visual Studio Code
- Git and GitHub

## How to Run
1. Place the project inside C:\xampp\htdocs.
2. Start Apache and MySQL from XAMPP.
3. Open http://localhost:8080/apexplanet-php/task-1/ in a browser.
